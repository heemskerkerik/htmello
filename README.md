# Htmello

This is a proof-of-concept Trello clone using (mostly) htmx. It’s intended as a companion to [this blog post](https://www.erikheemskerk.nl/htmx-trello-clone/).

## Running locally

The repository doesn’t have any infrastructural dependencies, so it’s easy to run it locally.

1. Download and install the [.NET 8.0 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0) (or newer);
2. Clone the repository;
3. `dotnet run`
